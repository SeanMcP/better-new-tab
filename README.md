# Better New Tab

🆕 A Chrome new tab page with:

- A clock with time zone, 12/24-hour and seconds options
- A calendar you can browse by month
- A 7-day weather forecast from [Open-Meteo](https://open-meteo.com)
- Post-it notes that you can rearrange and group by color, stored only on this device
- Custom background and accent colors

## Install

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select the `extension` folder.

## Hide Chrome's footer

1. Click **Customize Chrome** at the bottom of the new tab page.
2. Turn off **Show footer on New Tab page**.
